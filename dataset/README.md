# Dataset

**Nama:** Default of Credit Card Clients
**Sumber:** UCI Machine Learning Repository
**Halaman:** https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
**Lisensi:** CC BY 4.0

## Ringkasan
- 30.000 observasi nasabah kartu kredit di Taiwan (April sampai September 2005).
- 23 variabel penjelas: limit kredit, faktor demografi, riwayat pembayaran, tagihan, dan jumlah pembayaran.
- Target: `default payment next month` (1 = gagal bayar, 0 = tidak).

## Sitasi
Yeh, I. C., & Lien, C. H. (2009). The comparisons of data mining techniques for the predictive accuracy of probability of default of credit card clients. *Expert Systems with Applications, 36*(2), 2473-2480.

Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository.
